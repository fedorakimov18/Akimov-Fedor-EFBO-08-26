# Практическая работа №6

Акимов Фёдор, ЭФБО-08-26

Три задачи с практического занятия №6 на C++. Задание 1 решено двумя способами,
задания 2 и 3 одним, всего 4 файла. Вывод сделан ровно как в формате вывода, без
лишнего текста.

## Задание 1

Квадрат N x N: выше побочной диагонали 0, на ней 1, ниже 2. Клетка (i, j) лежит на
побочной диагонали, если i + j = n - 1 (нумерация с нуля).

задание1_способ1.cpp: два вложенных цикла, для каждой клетки сравниваю i + j с n - 1.
Меньше значит 0, равно 1, больше 2.

задание1_способ2.cpp: клетки не проверяю. В строке i сначала идут n - 1 - i нулей, потом
одна 1, потом i двоек, поэтому печатаю их тремя циклами подряд.

## Задание 2

Карта грибов как в сапёре. Завёл массив mush[34][34], в нём 1 там, где гриб, и 0, где
пусто. Координаты с единицы, а нулевая и 33-я строки и столбцы всегда пустые, поэтому
при подсчёте соседей не надо проверять выход за край. Для каждой клетки: если гриб,
вывожу *, иначе складываю 8 соседних клеток, это и есть число грибов вокруг. В условии
написано "без пробелов", но в примере вывода пробелы есть, сделал как в примере.

## Задание 3

Последовательность "смотри и говори": каждый следующий член описывает предыдущий.
Например, 1211 это "одна 1, одна 2, две 1", значит дальше 111221. Первый член читаю
как строку, n - 1 раз строю следующий: иду по строке и считаю одинаковые цифры подряд.
Когда следующая цифра другая или строка кончилась, дописываю в новую строку количество и
саму цифру.

## Проверка

Задание 1: при N = 4 вывод как в примере, оба способа совпадают при всех N от 1 до 100.
Задание 2: пример 3 2 с грибами (1, 1) и (2, 2) даёт как в условии, грибы в углах поля
32 x 32 тоже считаются правильно. Задание 3: 1 4 даёт 1211, 1 7 даёт 13112221, 0 3
даёт 1110.
