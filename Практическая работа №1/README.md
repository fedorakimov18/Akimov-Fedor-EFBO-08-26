# Практическая работа №1

Акимов Фёдор, ЭФБО-08-26

Задача 3: за один цикл посчитать F(n) = 1! * 2! * ... * n!. Делал в Scratch 3, проект
в файле task3_factorial_product.sb3.

Второй цикл тут не нужен, потому что i! получается из (i-1)! умножением на i. Поэтому
факториал считается прямо в том же цикле, что и ответ.

Переменные: n это число от пользователя, i номер шага, p текущий факториал, F ответ.
Сначала i = 0, p = 1, F = 1. Потом n раз: i увеличивается на 1, p = p * i, F = F * p.
В конце в F лежит ответ.

Программа запускается по зелёному флажку и спрашивает n. Чтобы было видно, как всё
считается, спрайт на каждом шаге меняет костюм, поворачивается, подпрыгивает и говорит
текущие значения, а на сцене включены мониторы переменных. В конце спрайт говорит ответ.

Проверял: F(3) = 12, F(4) = 288, F(5) = 34560.
