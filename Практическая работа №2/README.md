Три задачи с практического занятия №1 на C++, каждая в своём файле.

## Задача 1

Надо поменять местами a и b без третьей переменной. Сделал через сумму:
a = a + b, b = a - b, a = a - b. После первой строчки в a лежит сумма, из неё вычитаю b
и получаю старое a, потом вычитаю новое b и получаю старое b.
Проверял на a = 4, b = 5, получилось a = 5, b = 4.

## Задача 2

Надо за один цикл посчитать F(n) = 1! * 2! * ... * n!. Каждый следующий факториал это
предыдущий, умноженный на i, поэтому в цикле я сначала домножаю factorial на i, а потом
домножаю на него ответ result. Например, для n = 4 выходит 1 * 2 * 6 * 24 = 288.
Взял unsigned long long, потому что числа растут очень быстро. Правильно считает до
n = 8, дальше переполнение.

## Задача 3

Надо убрать if из блока: если A = 0, то B = 2, иначе B = 1. A бывает только 0 или 1,
поэтому подходит формула B = 2 - A. При A = 0 получается 2, при A = 1 получается 1.
