## Задача 3

N студентов стоят в ряд, у каждого номер пары от 0 до 9, после которой он хочет уйти.
Если двое соседей хотят уйти после одной и той же пары, они уходят, а остальные
сдвигаются. Надо вывести, сколько студентов уйдёт. Сначала вводится N (не больше 1000),
потом N номеров через пробел.

Решал так: студенты по одному встают в конец ряда row, len это сколько в нём сейчас
человек. Если новый студент хочет уйти с той же пары, что и последний в ряду, они
уходят вдвоём и len уменьшается на 1, иначе он встаёт в ряд и len растёт на 1. В конце
ушло n - len студентов. Если подряд трое одинаковых, уходят двое, третий остаётся.

## Файлы

1_for_три_блока.cpp: обычный for (i = 0; i < n; i++).

2_for_без_инициализации.cpp: i = 0 задаётся при объявлении, поэтому for (; i < n; i++).

3_for_только_условие.cpp: for (; i < n;), а i++ перенёс в тело цикла.

4_while.cpp: while (i < n).

5_do_while.cpp: do-while. Он один раз выполняется в любом случае, поэтому обернул его
в if (n > 0), иначе при n = 0 программа ждала бы лишний ввод.

## Проверка
