# Контрольная работа №3

Акимов Фёдор, ЭФБО-08-26

Контрольная работа №3 состоит из двух практических работ:

- [Практическая работа №11](./Практическая%20работа%20№11): три задачи (маршрут по аудитории, пирожки, букет)
- [Практическая работа №12](./Практическая%20работа%20№12): лабиринт с pdf-файлами

В папке есть CMakeLists.txt, поэтому её можно открыть в CLion как проект, и каждая задача
будет отдельной конфигурацией запуска: pr11_task1, pr11_task2, pr11_task3, pr12_task1.
