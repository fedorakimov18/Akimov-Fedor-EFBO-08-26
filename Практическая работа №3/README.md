## Задача 2

МКАД 109 км, Вася едет со скоростью v, надо узнать, где он будет через t часов. Дорога
кольцевая, поэтому нужен остаток от деления v * t на 109. Если скорость отрицательная,
остаток в C++ тоже выходит отрицательным, поэтому формула такая: (v * t % 109 + 109) % 109.
Проверял: v = 60, t = 2 дают 11, а v = -60, t = 2 дают 98.

## Задача 5

С начала суток прошло n секунд, надо вывести время в формате h:mm:ss. Часы это
n / 3600 % 24, минуты n / 60 % 60, секунды n % 60. Чтобы минуты и секунды были из двух
цифр, вывожу отдельно x / 10 и x % 10.
Проверял: 3602 даёт 1:00:02, 129700 даёт 12:01:40.

## Виды программирования

Процедурный: каждая задача это одна функция (task2 и task5), main их просто вызывает.

Модульный: каждая задача в своём namespace (Mkad и Clock), внутри разбита на маленькие
функции.

Проектный: сначала объявления (структуры и прототипы функций), потом main, а сами
функции после main, как в структуре программы из методички.

Объектно-ориентированный: для каждой задачи свой класс (Biker и Clock), данные лежат
в private, а работа с ними через методы.
