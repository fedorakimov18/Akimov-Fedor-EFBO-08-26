# Практическая работа №8

Акимов Фёдор, ЭФБО-08-26

Три задачи с практического занятия №8 на C++, все через функции. Задача 1 решена двумя
способами, задачи 2 и 3 одним, всего 4 файла.

## Задача 1

Быстрое возведение a в степень n, число действий порядка log2(n). Ввод: a и n через
пробел.

задача1_способ1.cpp: рекурсия. Считаю half = a^(n/2), при чётном n ответ half * half,
при нечётном ещё умножаю на a. При n = 0 возвращаю 1.

задача1_способ2.cpp: цикл. Иду по битам n с младшего: если бит 1, умножаю ответ на a,
потом a возвожу в квадрат и делю n на 2.

## Задача 2

НОД двух чисел рекурсивной функцией по алгоритму Евклида: gcd(a, b) = gcd(b, a % b),
пока b не станет 0, тогда ответ a.

## Задача 3

Ханойская башня. Чтобы переложить n ингредиентов с салфетки from на to, перекладываю
верхние n - 1 на третью салфетку, потом самый большой на to, потом n - 1 обратно на него.
Всего получается 2^n - 1 перекладываний.

## Проверка

Задача 1: 10 12 даёт 1000000000000, оба способа совпали с точным ответом на 300 случайных
тестах. Задача 2: 9 12 даёт 3, ещё 200 случайных пар до 10^9 сверил с готовым НОД.
Задача 3: 2 даёт как в примере, для n от 1 до 12 проверил, что больший ингредиент ни разу
не кладётся на меньший и всё оказывается на третьей салфетке.
